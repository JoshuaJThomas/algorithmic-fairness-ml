# Algorithmic Fairness in Machine Learning

Research project investigating bias metrics and fairness mitigation strategies in ML classification models. Published as an IEEE-style research paper.

## Overview
Analyses how algorithmic bias manifests in classification tasks and evaluates mitigation approaches — reweighing, adversarial debiasing, and calibration — against standard fairness metrics including demographic parity, equalised odds, and individual fairness.

## Tech Stack
- Python 3.x
- Scikit-learn
- Pandas / NumPy
- Matplotlib / Seaborn

## Structure
```
notebooks/    # Jupyter notebooks with analysis
data/         # Dataset files
results/      # Output figures and metrics
report/       # IEEE-style research paper
```

## Run Locally
```bash
pip install -r requirements.txt
jupyter notebook notebooks/
```
